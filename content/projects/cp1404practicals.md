This is my working repository for CP1404 - Programming II at James Cook University, taken online in Trimester 2, 2025. I kept every week's practical work in its own folder, `prac_01` through to the end of the trimester, so the whole
trimester reads as a sequence rather than a single dump of finished files.

The exercises move through the fundamentals in order: loops and menus early on, then string formatting, exception
handling and file I/O, then lists, comprehensions and sorting, and CSV data. A few folders also carry a reflection file where I wrote down what I thought was working and what I wanted to fix. Those notes are the part I find most useful to look back on, because they show where I was actually stuck rather than just what I eventually submitted.

I tried to hold the code to the subject's standards throughout - PEP 8 plus the CP1404 style guide - and used the repo as normal version control practice rather than a one-off upload at the end.

**Tech used:** Python 3.13, PEP 8 / CP1404 style guide, Git and GitHub
